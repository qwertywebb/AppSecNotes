# 🚀 Cheatsheet: Reverse Engineering Tools
**Цель:** Быстро понять, какой инструмент использовать для какого типа файлов, чтобы получить читаемый исходный код (или его аналог).


### 1. Ghidra (Для нативного кода)

**Что читает:**
- **`PE`** (`.exe`, `.dll`) — Windows, написанные на C/C++ (НЕ .NET).
- **`ELF`** (Linux executables, `.so` библиотеки).
- **`Mach-O`** (macOS).
- **`Firmware`**, **`Bootloaders`**.
- **`.o`** (Объектные файлы).

**Что умеет:**
- **Декомпиляция:** Превращает машинный код в читаемый **C-подобный код**.
- **Дизассемблер:** Показывает ассемблерные инструкции (Intel / ARM).
- **Навигация:** Поиск строк, функций, кросс-ссылок (XREF).

**Запуск (Linux):**
```bash
ghidra
```
**Формат вывода:** Си (псевдокод).


### 2. ILSpy / dnSpy (Для .NET кода)

**Что читают:**
- **`PE`** (`.exe`, `.dll`), написанные на **C#, VB.NET, F#**.
- **`.netmodule`**, **`.winmd`**.

**Что умеют:**
- **Декомпиляция в C#:** Восстанавливают исходный код (классы, методы, свойства) почти полностью.
- **Анализ IL:** Показывают промежуточный язык (MSIL) для низкоуровневого анализа.

**Запуск (Linux):**
```bash
# 1. ILSpy (консоль)
ilspycmd file.exe > decompiled.cs

# 2. dnSpy (GUI, через Wine)
wine dnSpy.exe
```
**Формат вывода:** C#, IL, или VB.


### 3. Другие инструменты (Бонус)

| Инструмент | Что читает | Формат вывода | Команда |
| :--- | :--- | :--- | :--- |
| **jd-gui** | `.jar`, `.class` (Java) | Java | `jd-gui file.jar` |
| **jadx** | `.apk`, `.dex`, `.aar` (Android) | Java | `jadx app.apk` |
| **pycdc** | `.pyc` (скомпилированный Python) | Python | `pycdc file.pyc` |
| **radare2** | Любой бинарник | Ассемблер | `r2 -A file.bin` |
| **strings** | Любой бинарник | ASCII/Unicode строки | `strings file.exe` |
