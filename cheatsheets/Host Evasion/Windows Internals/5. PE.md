

## 1. Что такое PE-формат

**PE (Portable Executable)** — это формат файлов `.exe`, `.dll`, `.sys` в Windows.  
Он определяет, как устроен исполняемый файл: где код, где данные, где импорты.

## 2. Структура PE-файла (7 основных компонентов)

| Компонент | Что делает |
| :--- | :--- |
| **DOS Header** | Начинается с `MZ`. Указывает, что это `.exe`. |
| **DOS Stub** | Маленькая программа. Выводит: *«This program cannot be run in DOS mode»*. |
| **PE Header** | Содержит сигнатуру `PE` (`50 45`). Определяет тип файла. |
| **Image Optional Header** | Важная часть (несмотря на название). Содержит точку входа, размеры, адреса. |
| **Data Dictionaries** | Указывают на таблицы импортов, экспортов, ресурсов. |
| **Section Table** | Описывает секции (`.text`, `.data`, `.rdata`, `.rsrc` и т.д.). |
| **Sections** | Сами данные: код, строки, ресурсы, импорты. |


## 3. Основные секции (разделы)

| Секция | Что там лежит |
| :--- | :--- |
| **.text** | Исполняемый код (машинные инструкции) |
| **.data** | Инициализированные данные (строки, переменные) |
| **.rdata / .idata** | Импорты (какие DLL и функции используются) |
| **.rsrc** | Ресурсы (иконки, картинки, меню) |
| **.reloc** | Информация для перемещения (релокации) |
| **.debug** | Отладочная информация |


## 4. Что ищут в PE-файлах при анализе

| Что ищут | Где искать |
| :--- | :--- |
| **Точка входа (Entry Point)** | В `Image Optional Header` → `AddressOfEntryPoint` |
| **Количество секций** | В `PE Header` → `NumberOfSections` |
| **Виртуальный адрес секции** | В `Section Table` → `VirtualAddress` |
| **Строки / данные** | В секции `.data` или `.rdata` по смещению |


## 5. Что такое виртуальный адрес (VA) и Relative Virtual Address (RVA)

| Термин | Что значит |
| :--- | :--- |
| **Virtual Address (VA)** | Полный адрес в виртуальной памяти (например, `0x7FF6A8A00000`) |
| **Relative Virtual Address (RVA)** | Смещение от базового адреса загрузки (например, `0x1000`) |
| **Entry Point** | Адрес, с которого начинается выполнение программы |

**Простыми словами:**  
RVA — это «сколько шагов от начала».  
VA — это «где это лежит в памяти».

## 6. Важно понять

**Виртуальные адреса, точки входа, смещения — это всё адреса в памяти, но на разных уровнях:**

| Что | Где находится |
| :--- | :--- |
| **Entry Point** | Виртуальный адрес (RVA) внутри секции `.text` |
| **VirtualAddress секции** | RVA, по которому секция загружается в память |
| **Смещение в файле** | Позиция в самом `.exe` файле (не в памяти) |

Эти адреса **нужны для загрузки файла в память** и для того, чтобы операционная система знала, где искать код и данные.


## 📌 Итог

> **PE-формат** — это «карта» исполняемого файла.  
> Он говорит Windows, где лежит код, где данные, с чего начинать выполнение.  
> **Точка входа** — это адрес, с которого начинается программа.  
> **Секции** — это блоки с кодом, данными и ресурсами.
