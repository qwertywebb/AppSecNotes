# DLL (Dynamic-Link Libraries)

## 1. Что такое DLL

**DLL (Dynamic-Link Library)** — это библиотека, содержащая код и данные, которые могут использоваться **несколькими программами одновременно**.

**Простыми словами:**  
Это как общая кухня в офисе — одна и та же, но ею пользуются все сотрудники (программы). Вместо того чтобы каждой программе иметь свою копию кода, они используют общую DLL.


## 2. Зачем нужны DLL

| Преимущество | Что это значит |
| :--- | :--- |
| **Модульность** | Код разбит на части, легче обновлять |
| **Повторное использование** | Одна DLL используется многими программами |
| **Экономия памяти** | Код загружается один раз для всех |
| **Экономия места** | Не нужно хранить одинаковый код в каждой программе |


## 3. Как программа использует DLL

Есть **два способа** загрузить DLL:

| Способ | Как работает |
| :--- | :--- |
| **Загрузка при запуске** (Load-time) | DLL загружается сразу при старте программы (нужен `.h` и `.lib` файлы) |
| **Загрузка во время выполнения** (Run-time) | DLL загружается по команде `LoadLibrary()` прямо во время работы программы |


### 📌 Пример загрузки во время выполнения (злоумышленники часто используют именно его):

```cpp
HINSTANCE hinstDLL = LoadLibrary("sampleDLL.dll");  // загружаем DLL
HelloWorld = (DLLPROC) GetProcAddress(hinstDLL, "HelloWorld");  // находим функцию
HelloWorld();  // выполняем
FreeLibrary(hinstDLL);  // выгружаем
```

**Почему это любят злоумышленники:**  
Можно передать только один файл (DLL) без дополнительных заголовков.


## 4. Что такое DllMain

Это **точка входа** в DLL — функция, которая вызывается автоматически при загрузке и выгрузке DLL.

```cpp
BOOL APIENTRY DllMain(HANDLE hModule, DWORD ul_reason_for_call, LPVOID lpReserved)
{
    return TRUE;
}
```


## 5. Как злоумышленники используют DLL

| Техника | Описание |
| :--- | :--- |
| **DLL Hijacking** (T1574.001) | Подмена легитимной DLL на вредоносную |
| **DLL Side-Loading** (T1574.002) | Загрузка вредоносной DLL из доверенной папки |
| **DLL Injection** (T1055.001) | Внедрение DLL в другой процесс |


## 6. Почему это работает

Windows ищет DLL в определённом порядке:
1. Папка приложения
2. Системные папки (`C:\Windows\System32`)
3. Переменная `PATH`

Если злоумышленник подкладывает DLL в папку приложения **раньше**, чем система найдёт оригинал — его DLL загружается вместо легитимной.


## 📌 Итог

> **DLL** — это библиотека с кодом, которую используют несколько программ.  
> Злоумышленники подменяют или внедряют DLL, чтобы выполнять свой код внутри чужих процессов.  
> **DllMain** — точка входа, которая выполняется при загрузке DLL.
