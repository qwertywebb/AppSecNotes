# 📘 Win32 API - компоненты

## 1. Что такое Win32 API

**Win32 API** (Windows API) — это основной набор функций, которые Windows предоставляет программам для взаимодействия с системой.  
Это **мост** между приложением (User Mode) и ядром (Kernel Mode).


## 2. Структура Win32 API (Top-Down)

| Уровень | Что это | Пример |
| :--- | :--- | :--- |
| **API** | Общий термин для всех вызовов Win32 | `CreateProcess`, `ReadFile`, `MessageBox` |
| **Header files / Imports** | Определяют, какие библиотеки подключать | `#include <windows.h>` |
| **Core DLLs** | 4 основные DLL, без которых ничего не работает | `KERNEL32.dll`, `USER32.dll`, `ADVAPI32.dll` |
| **Supplemental DLLs** | Дополнительные DLL для конкретных подсистем | `NTDLL.dll`, `COM.dll`, `FVEAPI.dll` |
| **Call Structures** | Определяют саму функцию и её параметры | `STARTUPINFO`, `PROCESS_INFORMATION` |
| **Calls** | Непосредственно вызов функции | `CreateProcess(...)` |
| **In/Out Parameters** | Параметры, которые передаются в функцию и из неё | `lpCommandLine`, `lpProcessInformation` |


## 3. Core DLLs (Основные 4 DLL)

| DLL | Что делает |
| :--- | :--- |
| **KERNEL32.dll** | Управление памятью, процессами, потоками, файловой системой |
| **USER32.dll** | Окна, кнопки, сообщения, GUI |
| **ADVAPI32.dll** | Безопасность, реестр, управление учетными записями |
| **GDI32.dll** | Графика, вывод на экран, печать |


## 4. Как программа использует Win32 API

```
[Программа] → вызывает → [Функцию Win32 API]
                                   ↓
                        [Загружает DLL (KERNEL32, USER32...)]
                                   ↓
                        [Передаёт параметры в функцию]
                                   ↓
                        [Windows выполняет действие]
```


## 5. Почему это важно для пентеста

| Знание | Как помогает |
| :--- | :--- |
| **Какие DLL используются** | Можно перехватывать вызовы (API Hooking) |
| **Какие параметры передаются** | Можно понять, что делает программа |
| **Какие функции доступны** | Можно искать уязвимые вызовы (например, `CreateRemoteThread`) |
| **Структуры данных** | Помогают анализировать вредоносное ПО |


## 6. Пример (реальный код)

```c
#include <windows.h>   // Header file

int main() {
    HANDLE hFile = CreateFile(          // Call
        "C:\\test.txt",                 // In Parameter
        GENERIC_READ,                   // In Parameter
        0, NULL, OPEN_EXISTING, 0, NULL // In Parameters
    );
    // hFile — Out Parameter (дескриптор файла)
    return 0;
}
```


## 📌 Итог

> **Win32 API** — это набор функций, через которые программы общаются с Windows.  
> Он построен на **DLL** (KERNEL32, USER32, ADVAPI32) и использует **структуры** для передачи данных.  
> Понимание Win32 API помогает в анализе вредоносного ПО, написании эксплойтов и понимании Windows Internals.
