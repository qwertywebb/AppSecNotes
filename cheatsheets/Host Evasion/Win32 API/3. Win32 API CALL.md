# 📘 Win32 API Calls — Имена, параметры и где искать

## 1. Структура имени Win32 API

Большинство Win32 API имеют **суффиксы**, которые указывают на тип кодировки или расширенную функциональность:

| Суффикс | Значение | Пример |
| :--- | :--- | :--- |
| **A** | **ANSI** — 8-битная кодировка (для старых программ) | `MessageBoxA` |
| **W** | **Wide** — Unicode (UTF-16) для современных приложений | `MessageBoxW` |
| **Ex** | **Extended** — расширенная версия с доп. параметрами | `CreateProcessEx` |

**Важно:** В современных Windows-приложениях чаще используют `W` (Unicode), потому что это стандарт для Windows NT.


## 2. Параметры API (In / Out)

Каждый API имеет **входные (in)** и **выходные (out)** параметры:

| Тип | Что означает | Пример |
| :--- | :--- | :--- |
| `[in]` | Значение **передаётся** в функцию | `HANDLE hProcess` |
| `[out]` | Функция **записывает** результат сюда | `SIZE_T *lpNumberOfBytesWritten` |
| `[in, out]` | Значение передаётся **и** может быть изменено | `LPVOID lpBuffer` |


## 3. Пример: `WriteProcessMemory`

```c
BOOL WriteProcessMemory(
  [in]  HANDLE  hProcess,           // Дескриптор процесса (куда пишем)
  [in]  LPVOID  lpBaseAddress,      // Адрес в памяти процесса
  [in]  LPCVOID lpBuffer,           // Буфер с данными для записи
  [in]  SIZE_T  nSize,              // Сколько байт записать
  [out] SIZE_T  *lpNumberOfBytesWritten // Сколько байт реально записано
);
```


## 4. Где искать информацию об API

| Источник | Для чего | Ссылка |
| :--- | :--- | :--- |
| **Microsoft Docs** | Официальная документация по всем API | [docs.microsoft.com](https://docs.microsoft.com/en-us/windows/win32/api/) |
| **pinvoke.net** | Примеры использования API в C# / .NET | [pinvoke.net](http://pinvoke.net/) |
| **C++ Reference** | Синтаксис и примеры на C++ | [cppreference.com](https://en.cppreference.com/w/cpp) |


## 5. Как искать API (пошагово)

1. **Введи название в Google:**  
   `WriteProcessMemory site:docs.microsoft.com`
2. **Найди функцию** → посмотри её параметры и суффиксы.
3. **Найди пример использования** (на pinvoke.net, если ты на C#).
4. **Определи константы** (например, `0x00080000` в `VirtualAlloc` — это `MEM_RESERVE`).


## 📌 Итог

> **Суффиксы API:** `A` — ANSI, `W` — Unicode, `Ex` — Extended.  
> **Параметры:** `[in]` — входной, `[out]` — выходной.  
> **Где искать:** Microsoft Docs и pinvoke.net — два главных источника.  
> **Константы:** часто ищи в заголовочных файлах Windows (`WinBase.h`, `MemoryAPI.h`).
