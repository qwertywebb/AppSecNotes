# LLM: Токены, Температура, Параметры 


## 1. Токенизация (Как LLM видит текст)

LLM не читают текст как человек. Они разбивают его на **токены** — минимальные единицы, которые модель может обработать.

- **1 токен** ≈ 3-4 символа (или 0.75 слова на английском).
- Короткие слова (`"the"`, `"cat"`) → 1 токен.
- Длинные слова (`"butterfly"`) → несколько токенов (`"butter"` + `"fly"`).
- `"ChatGPT"` → `"Chat"` + `"GPT"`.

**Как это работает:**
1. Текст разбивается на токены.
2. Каждый токен преобразуется в **числовой ID**.
3. Модель работает только с числами, предсказывая следующее число (токен).

**Разные модели → разная токенизация:**
- GPT → **Byte-Pair Encoding (BPE)**.
- BERT → **WordPiece**.


## 2. Детерминизм vs Недетерминизм

**Детерминизм:** Одинаковый вход → одинаковый выход (как в обычном ПО).
**Недетерминизм:** Одинаковый вход → разный выход (LLM).

**Почему:** LLM добавляет случайность при выборе следующего токена. Даже с температурой `0.0` полной детерминированности нет.

**Последствия для безопасности:**
- Вредоносный код выполняется одинаково всегда.
- Защита от вредоносного промпта может **сработать один раз, а в следующий — нет**.


## 3. Параметры управления (Как контролировать хаос)

### Температура (Temperature) — главный параметр

**Диапазон:** обычно `0.0 – 2.0` (зависит от провайдера).

| Температура | Поведение | Для чего использовать |
|-------------|-----------|------------------------|
| 0.0 – 0.3 | Всегда выбирает самый вероятный токен (почти детерминизм) | Код, факты, извлечение данных |
| 0.7 – 1.0 | Шире выборка, больше креативности | Мозговой штурм, маркетинг, истории |
| 1.2 – 1.5 | Начинает терять связность | Эксперименты |
| 1.5+ | Низкие вероятности доминируют (бред) | Не использовать |


### Max Tokens (Лимит длины)

Ограничивает **максимальную длину ответа**.

- 50–150 токенов → краткие ответы, саммари.
- 500–1000 токенов → детальные объяснения.
- 2000+ токенов → статьи, отчёты.

**Важно:** Это **потолок**, а не гарантия длины. Модель может остановиться раньше.


### Top-P (Nucleus Sampling) — альтернатива температуре

Вместо того чтобы менять "случайность" по всем словам, Top-P **отсекает маловероятные токены**.

- Top-P = 0.9 → модель рассматривает только токены, которые в сумме дают 90% вероятности.
- Чем выше Top-P → тем больше токенов в "шорт-листе".

**Правило:** Меняйте либо **температуру**, либо **Top-P**, но не оба вместе.


### Context Window (Окно контекста) — память модели

Максимальное количество токенов, которое модель может "помнить" в одном диалоге.

- GPT-3.5: 8k токенов.
- Claude 3.5: 200k токенов.
- Gemini 1.5: 1M+ токенов.

**Если превысить лимит** — модель обрезает начало диалога. Она **забывает**, что было в начале.


## 4. Итог

Параметры **не меняют знания** модели. Они меняют **способ выражения** этих знаний. Освоив их, вы сможете управлять моделью как настоящий инженер промптов.
