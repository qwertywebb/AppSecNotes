# Certificate Transparency (CT) Logs 

## Это самая эффективная техника пассивного обнаружения поддоменов
## Это публичная система ведения журналов о выпуске сертификатов, которая содержит  Subject Alternative Name (SAN) - это поле со списком охватываемых доменов и поддоменов.

### Пример использования

1. Перейти на сайт https://crt.sh
2. %.tryhackme.com

% - используется в качестве wildcard
