# Уклонение от файрвола при сканировании Nmap

## Зачем это нужно

Файрволы и системы обнаружения вторжений (IDS) реагируют на классические сканирования портов: множество SYN-пакетов с одного IP за короткое время — явный признак атаки. Nmap даёт набор опций, чтобы замаскировать источник, раздробить трафик и обойти правила файрвола.

Все приёмы делятся на три группы:

1. Управление источником (MAC/IP/порт)
2. Фрагментация, **MTU** и длина данных
3. Модификация полей заголовка


## Как выглядит обычное SYN-сканирование

Команда:

```bash
nmap -sS -Pn -F MACHINE_IP
```

- `-sS` — stealth (SYN) скан.
- `-Pn` — пропустить проверку живости хоста (обязательно, если хост за файрволом).
- `-F` — только 100 самых частых портов.

## 1. Decoy(s) — приманки

Идея: смешать свой реальный IP с чужими, чтобы файрвол не понял, кто настоящий источник.

```bash
nmap -sS -Pn -D 10.10.10.1,10.10.10.2,ME -F MACHINE_IP
```

- `-D` — список decoy-IP через запятую.
- `ME` — позиция твоего реального IP. Если не указать `ME`, Nmap поставит тебя в случайную позицию.

Случайные приманки:

```bash
nmap -sS -Pn -D RND,RND,ME -F MACHINE_IP
```

- `RND` — Nmap сам выберет случайные IP. Каждый запуск — новые.


Зачем: запутать blue team, растянуть расследование на множество IP.


## 2. Proxy — прокси

Идея: пустить скан через HTTP/SOCKS4-прокси, чтобы цель видела IP прокси, а не твой.

```bash
nmap -sS -Pn --proxies PROXY_URL -F MACHINE_IP
```

- `--proxies` — список прокси через запятую (цепочка поддерживается).
- Цель логирует IP прокси.

## 3. Spoofed MAC — подмена MAC-адреса

```bash
nmap --spoof-mac MAC_ADDRESS
```

- Работает **только в пределах одного Ethernet-сегмента** (L2). Если цель за маршрутизатором — ответы до тебя не дойдут.
- Применение: обойти доверие по MAC, спрятать скан под видом принтера и т.п.

## 4. Spoofed IP — подмена IP-адреса

```bash
nmap -S IP_ADDRESS
```

- Работает, только если ты в одной подсети с целью **или** контролируешь спуфируемый IP.
- Иначе ответы уйдут «не туда», и ты их не увидишь.
- Полезно, чтобы обойти trust-relationship по IP или переключиться на другой спуф, когда цель забанила первый.

## 5. Fixed Source Port — фиксированный исходный порт

```bash
nmap -g PORT_NUM
# или
nmap --source-port PORT_NUM
```

- Пакеты с source-портом 53/80/443 без анализа содержимого выглядят как DNS-ответы или веб-трафик.
- Если файрвол разрешает входящие от этих портов — скан пройдёт.


## Сводная таблица

| Приём | Опция Nmap |
|---|---|
| Приманки (decoy) | `-D IP1,IP2,ME` |
| Случайные приманки | `-D RND,RND,ME` |
| HTTP/SOCKS4-прокси | `--proxies PROXY_URL` |
| Подмена MAC | `--spoof-mac MAC_ADDRESS` |
| Подмена IP | `-S IP_ADDRESS` |
| Фиксированный source-порт | `-g PORT` / `--source-port PORT` |

## Логика применения

- **Decoy** — скрыть, кто настоящий источник, среди множества ложных.
- **Proxy** — вообще не светить свой IP, цель видит прокси.
- **Spoof MAC** — обман внутри одного сегмента L2.
- **Spoof IP** — обман при контроле спуфируемого адреса (или в одной подсети).
- **Fixed source port** — обход правил файрвола, доверяющего определённым портам (53, 80, 443).
