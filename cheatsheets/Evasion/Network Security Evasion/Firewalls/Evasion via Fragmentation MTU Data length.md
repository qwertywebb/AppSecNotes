# Фагментация и изменение размера пакетов в Nmap

## Зачем это нужно

Файрволы и IDS/IPS часто **не собирают фрагментированные пакеты** или **не проверяют их содержимое**. Если разбить пакет на части, фильтр может **пропустить** их, а **целевая система соберёт** и обработает. Это классический приём обхода защиты.

Nmap даёт **четыре** инструмента для этого.


## 1. `-f` — фрагментация по 8 байт

```bash
nmap -sS -Pn -f -F MACHINE_IP
```

**Что делает:** разбивает **IP-данные** на куски по **8 байт**.

**Сколько будет пакетов:**

- **TCP-заголовок** = **24 байта**.
- **24 ÷ 8 = 3** → **3 IP-пакета**.

**Размер IP-пакета:**

- **IP-заголовок** = **20 байт**.
- **Данные** = **8 байт**.
- **Итого** = **20 + 8 = 28 байт**.


## 2. `-ff` — фрагментация по 16 байт

```bash
nmap -sS -Pn -ff -F MACHINE_IP
```

**Что делает:** разбивает **IP-данные** на куски до **16 байт**.

**Сколько будет пакетов:**

- **24 байта** TCP-заголовка → **16 + 8** → **2 IP-пакета**.

**Максимальный размер IP-пакета:**

- **IP-заголовок** = **20 байт**.
- **Данные** = **16 байт** (**максимум** при `-ff`).
- **Итого** = **20 + 16 = 36 байт**.

## 3. `--mtu VALUE` — фрагментация по заданному размеру

```bash
nmap -sS -Pn --mtu 8 -F MACHINE_IP
```

**Что делает:** задаёт **размер IP-данных** (без IP-заголовка).

**Правила:**

- **Значение** **должно** **быть** **кратно 8**.
- **`--mtu 8`** = **`-f`** (8 байт данных).
- **`--mtu 16`** = **`-ff`** (16 байт данных).

**Пример:** `--mtu 36`:

- **Данные** = **36 байт**.
- **IP-заголовок** = **20 байт**.
- **Итого** = **20 + 36 = 56 байт**.

## 4. `--data-length NUM` — задать длину данных

```bash
nmap -sS -Pn --data-length 64 -F MACHINE_IP
```

**Что делает:** **добавляет** **случайные** **данные** **до** **указанной** **длины** **TCP-сегмента**.

**Правила:**

- **Значение** **кратно 8**.
- **Пакет** **становится** **больше**, **чем** **обычный** **SYN** (**24 байта** TCP-заголовка).
- **Цель:** **запутать** **IDS**, **который** **ждёт** **пакеты** **определённого** **размера**.

**Пример:** `--data-length 128`:

- **TCP-заголовок** = **24 байта**.
- **Данные** = **128 байт**.
- **IP-заголовок** = **20 байт**.
- **Итого** = **20 + 24 + 128 = 172 байта**.

**Ответ на вопрос:** **172 байта**.

## Сводная таблица

| Опция | Что делает | Размер данных | Размер IP-пакета |
|---|---|---|---|
| **`-f`** | Фрагментация по 8 байт | 8 байт | **28 байт** |
| **`-ff`** | Фрагментация по 16 байт | 16 байт | **36 байт** |
| **`--mtu 8`** | То же, что `-f` | 8 байт | 28 байт |
| **`--mtu 36`** | Данные 36 байт | 36 байт | **56 байт** |
| **`--data-length 64`** | Данные 64 байта | 64 байта | 20 + 24 + 64 = **108 байт** |
| **`--data-length 128`** | Данные 128 байт | 128 байт | 20 + 24 + 128 = **172 байта** |

## Формулы для запоминания

**Фрагментация (`-f`, `-ff`, `--mtu`):**

```
Размер IP-пакета = 20 (IP-заголовок) + размер данных
```

**`-f`** → 20 + 8 = **28**
**`-ff`** → 20 + 16 = **36**
**`--mtu 36`** → 20 + 36 = **56**

**`--data-length`:**

```
Размер IP-пакета = 20 (IP) + 24 (TCP) + длина данных
```

**`--data-length 128`** → 20 + 24 + 128 = **172**

## Ключевые моменты

1. **`-f`** = 8 байт, **`-ff`** = 16 байт.
2. **`--mtu`** — **кратно 8**, **не включает** IP-заголовок.
3. **`--data-length`** — **кратно 8**, **включает** TCP-заголовок.
4. **IP-заголовок** = **20 байт** (всегда).
5. **TCP-заголовок** = **24 байта** (SYN-скан).
6. **Фрагментация** обходит фильтры, которые **не собирают** пакеты.
7. **`--data-length`** обходит фильтры, которые **ищут** пакеты **определённого** **размера**.

## Быстрая шпаргалка

```bash
# Фрагментация по 8 байт
nmap -sS -Pn -f -F <target>

# Фрагментация по 16 байт
nmap -sS -Pn -ff -F <target>

# Фрагментация по MTU (кратно 8)
nmap -sS -Pn --mtu 36 -F <target>

# Данные заданной длины (кратно 8)
nmap -sS -Pn --data-length 128 -F <target>
```
