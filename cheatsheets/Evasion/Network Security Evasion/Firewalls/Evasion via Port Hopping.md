# Port hopping и проверка доступности портов

## Что проверяется

Не «открыт ли порт на удалённой машине», а **может ли удалённая машина подключиться к тебе** на определённый порт. То есть — **пропускает ли её файрвол исходящее соединение** на этот порт.

## Что где запускается

| Где | Команда | Что делает |
|---|---|---|
| **Твоя машина** | `ncat -lvnp 23` | **Слушает** входящее на порт 23 |
| **Удалённая машина** | `ncat <ТВОЙ_IP> 23` | **Пытается подключиться** к тебе на порт 23 |

## Почему соединение не проходит

Слушатель на твоей машине — это **открытая дверь** у тебя. Удалённая машина **пытается выйти** из своей сети и **дойти** до твоей двери.

Если соединение не проходит — значит, **файрвол на удалённой машине блокирует исходящий трафик** на этот порт. **Она не может выйти** — твоя дверь тут ни при чём.

## Как понять результат

- **На твоей машине появилось `Connection from ...`** → **порт доступен** (файрвол удалённой машины пропускает).
- **Тишина** → **порт заблокирован** (файрвол не пускает).

## Как проверить несколько портов

1. На своей машине — слушатель на каждом:
   ```bash
   sudo ncat -lvnp 21
   sudo ncat -lvnp 23
   sudo ncat -lvnp 25
   sudo ncat -lvnp 26
   sudo ncat -lvnp 27
   ```
   (порты **< 1024** — нужен **`sudo`**)

2. С удалённой машины — подключение к каждому:
   ```bash
   ncat <ТВОЙ_IP> 21
   ncat <ТВОЙ_IP> 23
   ncat <ТВОЙ_IP> 25
   ncat <ТВОЙ_IP> 26
   ncat <ТВОЙ_IP> 27
   ```

3. **Смотри на своей машине**: где появилось `Connection from ...` — **тот порт доступен**.

## Итог

- **Слушатель — у тебя.**
- **Подключение — с удалённой машины.**
- **Не проходит** = **файрвол удалённой машины блокирует исходящее** на этот порт.
- **Проходит** = **порт доступен** из её сети.
