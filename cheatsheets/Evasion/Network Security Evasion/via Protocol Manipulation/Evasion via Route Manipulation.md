**Обход IDS/IPS через манипуляцию маршрутом**

### 🎯 Главная цель

Мы хотим **скрыть источник атаки** или **направить трафик в обход IDS/IPS**. Для этого манипулируем **маршрутизацией**.

**2 подхода:**
1. **Source Routing** (маршрутизация от источника).
2. **Proxy Servers** (прокси-серверы).


### 1. Source Routing (маршрутизация от источника)

**Суть:** Ты **сам указываешь маршрут**, по которому пойдут пакеты, вместо того чтобы полагаться на стандартную маршрутизацию.

**Инструмент:** `nmap` с опцией `--ip-options`.

**Два типа маршрутизации:**

| Тип | Флаг | Что делает |
|-----|------|------------|
| **Loose (свободная)** | `L` | Указываешь **несколько ключевых точек**, между ними маршрут определяется автоматически |
| **Strict (строгая)** | `S` | Указываешь **каждый хоп** между тобой и целью |

**Примеры:**

**Loose:**
```bash
nmap --ip-options "L 10.10.10.50 10.10.50.250" TARGET
```
**Пакеты пойдут через `10.10.10.50` и `10.10.50.250`.**

**Strict:**
```bash
nmap --ip-options "S 10.10.10.1 10.10.20.2 10.10.30.3" TARGET
```
**Пакеты пойдут строго через эти три хопа.**

**Когда использовать:**
- **Обход IDS/IPS**, если он **не проверяет** определённые маршруты.
- **Достижение цели** через **альтернативный путь**.
- **Маскировка источника** (если маршрут проходит через **доверенные сети**).


### 2. Proxy Servers (прокси-серверы)

**Суть:** Ты **прячешь свой IP**, направляя трафик через **промежуточные серверы**.

**Инструмент:** `nmap` с опцией `--proxies`.

**Формат:**
```
--proxies proto://host:port,proto://host:port,...
```

**Поддерживаемые протоколы:**
- **HTTP**
- **SOCKS4**

**Аутентификация:** **не поддерживается**.

**Пример:**
```bash
nmap -sS HTTP://PROXY_HOST1:8080,SOCKS4://PROXY_HOST2:4153 TARGET
```

**Что происходит:**
1. **Nmap** отправляет трафик на **PROXY_HOST1** (HTTP).
2. **PROXY_HOST1** перенаправляет на **PROXY_HOST2** (SOCKS4).
3. **PROXY_HOST2** отправляет на **TARGET**.
4. **Цель видит** только **последний прокси**, а не твой IP.

**Когда использовать:**
- **Скрытие источника** (цель не знает твой IP).
- **Обход блокировок** (если твой IP в чёрном списке).
- **Тестирование из разных регионов**.

**Недостатки:**
- **Нужно найти надёжный прокси** (trial and error).
- **Скорость падает** (трафик идёт через посредников).
- **Прокси может логировать** твой трафик.


### 3. Прокси для других инструментов

**Веб-браузер:**
- **Настройки прокси** в браузере или через **расширения** (FoxyProxy).
- **Burp Suite** — можно направить трафик через него.

**Другие инструменты:**
- **`curl`:** `curl --proxy socks5://127.0.0.1:9050 https://target`
- **`wget`:** `wget -e use_proxy=yes -e http_proxy=...`
- **`proxychains`:** для **любых** инструментов (например, `proxychains nmap ...`).


### 📌 Итог

| Подход | Инструмент | Когда использовать |
|--------|------------|-------------------|
| **Source Routing** | `nmap --ip-options "L ..."` или `"S ..."` | Обход IDS, альтернативный маршрут |
| **Proxy Servers** | `nmap --proxies HTTP://...,SOCKS4://...` | Скрытие источника, обход блокировок |
| **Proxychains** | `proxychains <команда>` | Любые инструменты через прокси |

**Ключевое:**
- **Source Routing** — **указываешь маршрут**.
- **Proxy Servers** — **скрываешь источник**.
- **Оба подхода** — **обход IDS/IPS**.

**Без обхода маршрута — IDS может заблокировать твой трафик.** 🚀
