**Обход IDS/IPS (Evasion via Protocol Manipulation)**

### 🎯 Главная цель

Мы хотим **обмануть IDS/IPS**, чтобы наш трафик **не совпал с сигнатурами** атак. Для этого манипулируем **протоколами**.

**4 подхода:**
1. Использовать **другой протокол**.
2. Манипулировать **портами** (TCP/UDP).
3. **Фрагментировать** пакеты (session splicing).
4. Отправлять **невалидные пакеты**.


### 1. Использовать другой протокол

**Суть:** IDS может **блокировать** одни протоколы и **разрешать** другие.

**Пример:** если DNS и HTTP запрещены, а **HTTPS разрешён** — используем **HTTPS** для туннеля.

**Как в Ncat:**
- По умолчанию **TCP**.
- С флагом **`-u`** — **UDP**.

| Задача | Команда |
|--------|---------|
| Слушать TCP | `ncat -lvnp PORT` |
| Подключиться TCP | `ncat IP PORT` |
| Слушать UDP | `ncat -ulvnp PORT` |
| Подключиться UDP | `ncat -u IP PORT` |

**Примеры маскировки:**
- `ncat -lvnp 25` — выглядит как **SMTP**.
- `ncat -ulvnp 162` — выглядит как **SNMP**.

**Важно:** если у IDS есть **DPI** (Deep Packet Inspection) — маскировка **не сработает**.


### 2. Манипуляция портами

**Суть:** IDS **смотрит на порт** и думает, что это **легитимный сервис**.

**Пример:**
- Порт **22** → IDS думает **SSH**.
- Порт **80** → IDS думает **HTTP**.

**Как в Nmap:**
| Задача | Команда |
|--------|---------|
| Маскировка под HTTP | `nmap -sS -Pn -g 80 -F TARGET` |
| Маскировка под DNS | `nmap -sU -Pn -g 53 -F TARGET` |

**`-g`** (или `--source-port`) — **исходный порт**.

**Как в Ncat:**
| Задача | Команда |
|--------|---------|
| Слушать как DNS (UDP 53) | `ncat -ulvnp 53` |
| Подключиться как DNS | `ncat -u ATTACKER_IP 53` |
| Слушать как HTTP (TCP 80) | `ncat -lvnp 80` |
| Подключиться как HTTP | `nc ATTACKER_IP 80` |

### 3. Фрагментация пакетов (Session Splicing)

**Суть:** Разбиваем **payload** на **маленькие пакеты**. Если IDS **не собирает** пакеты обратно — **сигнатура не сработает**.

**Как в Nmap:**
| Флаг | Что делает |
|------|------------|
| `-f` | Данные в IP-пакете → **8 байт** |
| `-ff` | Данные в IP-пакете → **16 байт** |
| `--mtu SIZE` | Кастомный размер (кратен **8**) |

**Как в Fragroute:**
- Файл `fragroute.conf`:
  ```
  ip_frag 16
  ```
- Запуск:
  ```
  fragroute -f fragroute.conf HOST
  ```

**`ip_frag 16`** — фрагменты **не больше 16 байт**.


### 4. Отправка невалидных пакетов

**Суть:** IDS **может обработать** невалидный пакет, а **цель — проигнорировать**. Поведение **непредсказуемо** — нужно **экспериментировать**.

**Как в Nmap:**
| Флаг | Что делает |
|------|------------|
| `--badsum` | **Неверная контрольная сумма** TCP/UDP |
| `--scanflags` | **Кастомные TCP-флаги** |

**Флаги TCP для `--scanflags`:**
- `URG` — Urgent
- `ACK` — Acknowledge
- `PSH` — Push
- `RST` — Reset
- `SYN` — Synchronize
- `FIN` — Finish

**Пример:** `--scanflags SYNRSTFIN` — SYN + RST + FIN одновременно.

**Как в hping3:**
| Флаг | Что делает |
|------|------------|
| `-t` / `--ttl` | Time to Live в IP-заголовке |
| `-b` / `--badsum` | Неверная контрольная сумма |
| `-S` | SYN |
| `-A` | ACK |
| `-P` | PSH |
| `-U` | URG |
| `-F` | FIN |
| `-R` | RST |

### 📌 Итог

| Подход | Инструмент | Ключевые опции |
|--------|------------|----------------|
| **Другой протокол** | Ncat | `-u` (UDP), порты 25/53/80/162 |
| **Манипуляция портами** | Nmap, Ncat | `-g`, `--source-port` |
| **Фрагментация** | Nmap, Fragroute | `-f`, `-ff`, `--mtu`, `ip_frag` |
| **Невалидные пакеты** | Nmap, hping3 | `--badsum`, `--scanflags` |

**Главное:** IDS без **DPI** обмануть **легко**. С **DPI** — сложнее, нужны **другие методы**.
