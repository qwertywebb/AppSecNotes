# Виртуальная память Windows (Virtual Memory)

## 1. Что такое виртуальная память

**Виртуальная память** — это механизм, который позволяет каждому процессу работать с памятью так, как будто он единственный в системе.

**Простыми словами:**  
Это как если бы у каждого приложения был свой собственный «личный кабинет» в памяти, и оно не знало о других кабинетах. Оно работает со своими адресами, а система сама переводит их в реальные адреса физической памяти.


## 2. Зачем это нужно

- **Изоляция процессов** — один процесс не может случайно или намеренно повредить память другого.
- **Безопасность** — процесс не видит чужие данные.
- **Эффективность** — система может использовать диск как «расширение» памяти (файл подкачки).


## 3. Как это работает

1. Каждому процессу выделяется **виртуальное адресное пространство**.
2. Процесс работает с виртуальными адресами.
3. **Менеджер памяти** (Memory Manager) преобразует виртуальные адреса в физические.
4. Если физической памяти не хватает, **страницы** (pages) памяти сохраняются на диск (файл подкачки).


## 4. Ограничения виртуальной памяти

| Архитектура | Максимальный размер виртуального адресного пространства |
| :--- | :--- |
| **32-bit x86** | 4 ГБ |
| **64-bit** | 256 ТБ |


## 5. Как делится адресное пространство (32-bit)

| Диапазон | Назначение |
| :--- | :--- |
| `0x00000000 — 0x7FFFFFFF` | **Пользовательский режим** — выделяется процессам |
| `0x80000000 — 0xFFFFFFFF` | **Режим ядра** — используется системой |


## 6. Как это связано с потоками и процессами

| Компонент | Что делает |
| :--- | :--- |
| **Процесс** | Имеет своё виртуальное адресное пространство |
| **Поток** | Выполняется внутри процесса и использует его память |
| **Виртуальная память** | Даёт каждому процессу изолированное пространство, в котором работают его потоки |


# Процессы, потоки и виртуальная память

## 1. Процесс (Process)

**Процесс** — это запущенная программа (например, `notepad.exe`).

**Что есть у процесса:**
- Свой **код** и **данные**
- Своё **виртуальное адресное пространство**
- Один или несколько **потоков**
- Ресурсы (открытые файлы, дескрипторы)


## 2. Поток (Thread)

**Поток** — это исполнитель внутри процесса.

**Что есть у потока:**
- **Стек** (данные вызовов)
- **Контекст** (регистры процессора)
- **TLS (Thread Local Storage)** — уникальные данные потока

**Важно:** Все потоки одного процесса разделяют его память и ресурсы.


## 3. Виртуальная память

**Виртуальная память** — это механизм, который:
- Даёт каждому процессу изолированное адресное пространство
- Преобразует виртуальные адреса в физические
- Позволяет использовать диск как дополнительную память


## 4. Взаимосвязь (как это всё работает вместе)

```
[ПРОЦЕСС] → имеет → [ВИРТУАЛЬНОЕ АДРЕСНОЕ ПРОСТРАНСТВО]
                                ↓
[ПОТОК] → выполняется внутри → использует память процесса
                                ↓
[МЕНЕДЖЕР ПАМЯТИ] → преобразует виртуальные адреса → в физические
```


## 5. Почему это важно для безопасности

| Атака | Как связана с этими концепциями |
| :--- | :--- |
| **Инъекция в процесс** | Злоумышленник внедряет код в чужой процесс, используя его память |
| **Перехват потоков** | Меняет контекст потока, чтобы выполнить свой код |
| **Обход защиты памяти** | Использует уязвимости в управлении виртуальной памятью |


## 6. Запомни

> **Процесс — это контейнер.**  
> **Поток — это исполнитель внутри контейнера.**  
> **Виртуальная память — это изолированное пространство, в котором работает контейнер.**
