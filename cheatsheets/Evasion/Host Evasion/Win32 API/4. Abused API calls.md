# Наиболее часто используемые Win32 API в Red Team и malware

## 1. Почему именно эти функции?

Windows предоставляет тысячи функций Win32 API.

Однако на практике вредоносные программы используют относительно небольшой набор функций.

Причина простая — именно они позволяют:

* получать информацию о системе;
* работать с памятью;
* загружать DLL;
* находить адреса других функций;
* запускать код.

Из-за этого антивирусы и EDR уделяют этим вызовам особое внимание.


# 2. Часто используемые Win32 API

## LoadLibraryA

**Назначение**

Загружает DLL в память процесса.

Например:

```text
LoadLibraryA("user32.dll")
```

После этого программа может использовать функции из этой DLL.

### Где используется

* загрузка библиотек во время выполнения;
* плагины;
* malware;
* обход статических импортов.


## GetUserNameA

**Назначение**

Возвращает имя текущего пользователя Windows.

Например:

```text
Administrator
John
Alice
```

### Где используется

Перед выполнением вредоносного кода malware может проверить:

* под каким пользователем запущена программа;
* есть ли права администратора;
* не находится ли программа в песочнице.


## GetComputerNameA

**Назначение**

Возвращает имя компьютера.

Например:

```text
DESKTOP-123ABC
```

### Где используется

Malware часто проверяет имя компьютера.

Например:

```text
WIN-TEST
SANDBOX
VMWARE
```

Если обнаруживается виртуальная машина или песочница, вредоносная программа может завершить работу.


## GetVersionExA

**Назначение**

Определяет версию Windows.

Например:

* Windows 10;
* Windows 11;
* Windows Server.

### Где используется

Некоторые техники работают только на определённых версиях Windows.

Поэтому сначала определяется версия ОС.


## GetModuleFileNameA

**Назначение**

Возвращает полный путь к исполняемому файлу.

Например:

```text
C:\Users\Admin\Desktop\program.exe
```

### Где используется

Позволяет узнать:

* откуда запущена программа;
* своё собственное расположение на диске.


## GetStartupInfoA

**Назначение**

Получает информацию о том, как был запущен процесс.

Например:

* стандартные потоки;
* рабочий стол;
* параметры запуска.

### Где используется

Используется при создании новых процессов и анализе текущего окружения.


## GetModuleHandle

**Назначение**

Возвращает адрес уже загруженной DLL.

Например:

```text
GetModuleHandle("kernel32.dll")
```

Если библиотека уже находится в памяти, загружать её повторно не нужно.

### Где используется

Очень часто применяется вместе с `GetProcAddress`.


## GetProcAddress

**Назначение**

Возвращает адрес функции внутри DLL.

Например:

```text
GetProcAddress(
    kernel32,
    "VirtualAlloc"
)
```

После этого программа получает настоящий адрес функции и может вызвать её.

### Где используется

Практически во всех загрузчиках, шеллкоде и многих инструментах Red Team.


## VirtualProtect

**Назначение**

Изменяет права доступа к области памяти.

Например:

Память была:

```text
Read + Write
```

После вызова:

```text
Read + Execute
```

или

```text
Read + Write + Execute
```

### Где используется

Очень часто применяется перед выполнением шеллкода.

Например:

```text
выделили память
        ↓
записали shellcode
        ↓
VirtualProtect
        ↓
разрешили выполнение
        ↓
запустили код
```

---

# 3. Почему это важно для Red Team

Эти функции постоянно встречаются в:

* malware;
* загрузчиках (loaders);
* инжекторах процессов;
* C2-агентах;
* инструментах Red Team.

Если ты видишь такой код:

```text
LoadLibrary
      ↓
GetModuleHandle
      ↓
GetProcAddress
      ↓
VirtualProtect
```

то, скорее всего, программа:

* получает адреса нужных функций;
* изменяет память;
* готовится выполнить собственный код.


# 📌 Итог

Самые важные функции, которые стоит запомнить на данном этапе:

| Функция             | Для чего нужна                         |
| :------------------ | :------------------------------------- |
| `LoadLibrary`       | Загружает DLL                          |
| `GetModuleHandle`   | Получает адрес уже загруженной DLL     |
| `GetProcAddress`    | Получает адрес функции внутри DLL      |
| `VirtualProtect`    | Меняет права доступа к памяти          |
| `GetUserName`       | Узнаёт имя текущего пользователя       |
| `GetComputerName`   | Узнаёт имя компьютера                  |
| `GetVersionEx`      | Определяет версию Windows              |
| `GetModuleFileName` | Возвращает путь к исполняемому файлу   |
| `GetStartupInfo`    | Получает информацию о запуске процесса |

### 💡 Что стоит запомнить

* **Работа с DLL:** `LoadLibrary`, `GetModuleHandle`, `GetProcAddress`.
* **Сбор информации о системе:** `GetUserName`, `GetComputerName`, `GetVersionEx`, `GetModuleFileName`, `GetStartupInfo`.
* **Работа с памятью:** `VirtualProtect`.
