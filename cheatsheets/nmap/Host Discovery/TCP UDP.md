# TCP/UDP Scan


## 1. TCP SYN Ping (`-PS`)

**Что делает:**  
Отправляет TCP-пакет с флагом **SYN** на указанный порт (по умолчанию порт 80).

**Как работает:**

| Порт | Ответ | Что это значит |
| :--- | :--- | :--- |
| **Открыт** | SYN/ACK | Хост жив |
| **Закрыт** | RST | Хост жив (порт закрыт, но хост ответил) |
| **Нет ответа** | — | Хост, скорее всего, выключен |

**Важно:**  
- **Привилегированный пользователь (root)** может отправить SYN и не завершать 3-way handshake.
- **Обычный пользователь** должен завершить handshake, даже если порт открыт.

**Команда:**
```bash
nmap -PS -sn TARGETS           # по умолчанию порт 80
nmap -PS21 -sn TARGETS         # порт 21
nmap -PS21-25 -sn TARGETS      # порты 21-25
nmap -PS80,443,8080 -sn TARGETS # несколько портов
```


## 2. TCP ACK Ping (`-PA`)

**Что делает:**  
Отправляет TCP-пакет с флагом **ACK** на указанный порт (по умолчанию порт 80).

**Как работает:**  
- Любой хост, получивший ACK-пакет, который не является частью существующего соединения, **обязан ответить RST**.
- Если хост отвечает RST → он жив.
- Только для привилегированных пользователей (root/sudo).

**Команда:**
```bash
nmap -PA -sn TARGETS
nmap -PA21 -sn TARGETS
nmap -PA80,443 -sn TARGETS
```


## 3. UDP Ping (`-PU`)

**Что делает:**  
Отправляет UDP-пакет на указанный порт.

**Как работает:**

| Порт | Ответ | Что это значит |
| :--- | :--- | :--- |
| **Открыт** | Нет ответа | Хост жив (но ничего не подтверждает) |
| **Закрыт** | ICMP Port Unreachable | Хост жив |
| **Нет ответа** | — | Хост, скорее всего, выключен |

**Важно:**  
- UDP-скан менее надёжен, потому что на открытые порты часто нет ответа.
- Лучше всего использовать **закрытые порты**, чтобы получить ICMP-ответ.

**Команда:**
```bash
nmap -PU -sn TARGETS
nmap -PU53 -sn TARGETS        # DNS-порт
nmap -PU161 -sn TARGETS       # SNMP
```


## 4. Почему `-PS`, а не `-sS`?

| Опция | Что делает | Уровень |
| :--- | :--- | :--- |
| **`-PS`** | **SYN Ping** — проверка, жив ли хост (Host Discovery) | Обнаружение хостов |
| **`-sS`** | **SYN Stealth Scan** — сканирование портов (Port Scanning) | Сканирование портов |

**Разница:**
- `-PS` — только проверяет, отвечает ли хост (не сканирует порты).
- `-sS` — сканирует порты на живом хосте (определяет, открыт порт или закрыт).

**Пример:**
```bash
# SYN Ping (только проверка жизни)
nmap -PS -sn 10.10.10.0/24

# SYN Stealth Scan (сканирование портов)
nmap -sS 10.10.10.1
```


## 5. Сравнение всех методов Host Discovery

| Метод | Опция | Когда использовать |
| :--- | :--- | :--- |
| **ARP** | `-PR` | Только в локальной сети |
| **ICMP Echo** | `-PE` | Внешняя сеть, если ICMP не заблокирован |
| **ICMP Timestamp** | `-PP` | Если Echo заблокирован |
| **ICMP Address Mask** | `-PM` | Редко работает |
| **TCP SYN Ping** | `-PS` | Если ICMP заблокирован |
| **TCP ACK Ping** | `-PA` | Привилегированный пользователь |
| **UDP Ping** | `-PU` | Если TCP заблокирован |


## 6. Masscan (быстрый аналог Nmap)

Masscan использует **SYN-сканирование** для быстрого обнаружения хостов.

**Примеры:**
```bash
masscan 10.200.6.0/24 -p443
masscan 10.200.6.0/24 -p80,443
masscan 10.200.6.0/24 -p22-25
```


## 📌 Итог

| Метод | Опция | Суть |
| :--- | :--- | :--- |
| **TCP SYN Ping** | `-PS` | Отправляет SYN, ждёт SYN/ACK или RST |
| **TCP ACK Ping** | `-PA` | Отправляет ACK, ждёт RST |
| **UDP Ping** | `-PU` | Отправляет UDP, ждёт ICMP Port Unreachable |

> `-PS` — это **Host Discovery** (проверка жизни), а `-sS` — это **Port Scanning** (определение состояния портов).
