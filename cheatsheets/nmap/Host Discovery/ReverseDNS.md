# ReverseDNS

## 1. Что такое Reverse DNS (rDNS)

**Reverse DNS** — это процесс **преобразования IP-адреса в доменное имя**.

| Тип | Вопрос | Пример |
| :--- | :--- | :--- |
| **Обычный DNS (Forward)** | «Какой IP у `example.com`?» | `example.com` → `93.184.216.34` |
| **Reverse DNS** | «Какое доменное имя у `93.184.216.34`?» | `93.184.216.34` → `example.com` |

**Зачем нужно:**  
- Узнать, какие сервисы работают на IP (например, `mail.company.local`, `dc01.domain.com`).
- Понять структуру сети (какие хосты для чего используются).
- Помогает при разведке (reconnaissance).


## 2. Как Nmap работает с rDNS

| Настройка | Что делает |
| :--- | :--- |
| **По умолчанию** | Nmap делает reverse lookup **только для живых хостов**. |
| **`-R`** | Принудительно делает reverse lookup **для всех хостов** (включая offline). |
| **`-n`** | **Отключает** reverse lookup (ускоряет сканирование). |


## 3. Когда использовать rDNS

| Сценарий | Рекомендация |
| :--- | :--- |
| **Разведка (recon)** | Включить `-R`, чтобы понять структуру сети. |
| **Быстрое сканирование** | Использовать `-n`, чтобы ускорить процесс. |
| **Точное определение ролей** | rDNS может показать `mail`, `dc`, `web`, `db` в именах хостов. |


## 4. Важные нюансы

- **rDNS не всегда настроен.**  
  Многие администраторы не настраивают PTR-записи для внутренних IP.
- **Может быть неточным.**  
  Имя хоста может не соответствовать реальной службе.
- **Замедляет сканирование.**  
  Каждый запрос к DNS-серверу добавляет задержку.


## 5. Команды

| Команда | Описание |
| :--- | :--- |
| `nmap -R TARGET` | Принудительно делает rDNS для всех хостов |
| `nmap -n TARGET` | Отключает rDNS (быстрее) |
| `nmap --dns-servers 8.8.8.8 TARGET` | Использовать конкретный DNS-сервер |

**Пример:**
```bash
# Включить rDNS для всех хостов
nmap -R 10.10.10.0/24

# Отключить rDNS (ускорить)
nmap -n 10.10.10.0/24

# Использовать Google DNS для reverse lookup
nmap --dns-servers 8.8.8.8 10.10.10.0/24
```

> rDNS помогает понять, какие сервисы работают на хосте, но **не всегда точен** и **замедляет сканирование**.  
> Используй `-R` для разведки и `-n` для быстрых сканов.
