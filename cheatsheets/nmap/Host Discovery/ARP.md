# Host Discovery


## 1. Зачем нужно обнаруживать хосты

**Цель:**  
Перед сканированием портов нужно понять, **какие хосты вообще живы** (online).  
Сканировать порты у выключенной машины — трата времени.


## 2. Как Nmap по умолчанию определяет живые хосты

Nmap использует комбинацию методов в зависимости от:
- **Привилегий** пользователя (root или обычный)
- **Типа сети** (локальная или внешняя)


## 3. Если пользователь — **root** (привилегированный)

| Сценарий | Что использует Nmap |
| :--- | :--- |
| **В локальной сети (Ethernet / Wi-Fi)** | **ARP-запросы** (`-PR`) |
| **Вне локальной сети** | ICMP echo, TCP ACK (порт 80), TCP SYN (порт 443), ICMP timestamp |


## 4. Если пользователь — **обычный (не root)**

| Сценарий | Что использует Nmap |
| :--- | :--- |
| **Вне локальной сети** | TCP SYN на порты 80 и 443 (3-way handshake) |


## 5. ARP-скан (только в локальной сети)

**ARP (Address Resolution Protocol)** — нужен, чтобы узнать MAC-адрес по IP-адресу.

### Как работает:

1. Nmap отправляет **ARP-запрос** на широковещательный адрес.
2. Запрос: «Кто имеет IP `x.x.x.x`? Сообщи свой MAC».
3. Живой хост отвечает: «Это я, мой MAC — `AA:BB:CC:DD:EE:FF`».

**Команда:**  
```bash
nmap -PR -sn TARGETS
```

- `-PR` — только ARP-скан
- `-sn` — не сканировать порты, только обнаружить хосты

**Важно:** ARP работает **только в одной подсети** (Layer 2).


## 6. ICMP-скан (внешняя сеть)

Когда ARP недоступен, Nmap использует ICMP:

| Тип ICMP | Назначение |
| :--- | :--- |
| **Echo Request** | Классический «пинг» |
| **Timestamp Request** | Запрос времени |
| **TCP ACK на порт 80** | Проверка, отвечает ли веб-сервер |
| **TCP SYN на порт 443** | Проверка HTTPS-сервера |

**Команда:**  
```bash
nmap -sn TARGETS
```


## 7. Что делает `-sn` (ping scan)

- Отключает сканирование портов.
- Только проверяет, какие хосты живы.
- Это полезно для быстрой разведки.


## 8. Разница между `-PR` и `-sn`

| Флаг | Что делает |
| :--- | :--- |
| `-PR` | Только ARP-запросы (локальная сеть) |
| `-sn` | Проверка жизни хоста (без портов) |
| `-PR -sn` | ARP-скан + не сканировать порты |


## 9. Наглядный пример

```bash
nmap -PR -sn 10.200.6.0/24
```

- Сканирует подсеть `/24`
- Использует ARP для обнаружения живых хостов
- Не сканирует порты

Результат:
```
Nmap scan report for 10.200.6.228
Host is up.
```


## 10. Почему ARP-скан важен для пентеста

| Сценарий | Почему полезно |
| :--- | :--- |
| **Пост-эксплуатация** | После взлома хоста можно быстро найти соседние машины |
| **Внутренняя сеть** | ARP часто не блокируется фаерволлами |
| **Red Team / пентест** | Быстрое обнаружение живых целей |


## 🔥 Важно запомнить

> **ARP-скан — самый быстрый и надёжный способ обнаружения хостов в локальной сети.**  
> **Он работает только в одной подсети и не блокируется фаерволлами.**
