# Конспект по ICS/SCADA для пентеста


## 1. Термины

* ICS (Industrial Control Systems) — «Промышленные системы управления»
Что это: Это всё железо и софт, которые управляют промышленными процессами.
В ICS входит:

PLC (программируемые логические контроллеры) — мозги станка или помпы.

DCS (распределённые системы управления) — для больших заводов.

RTU (удалённые терминалы) — для управления объектами на расстоянии.

Датчики, исполнительные механизмы, панели оператора.

Пример ICS: Контроллер, который включает и выключает помпу на насосной станции.

* SCADA (Supervisory Control and Data Acquisition) — «Диспетчерское управление и сбор данных»
Что это: Это надстройка над ICS. SCADA — это не железо, а софт, который:

Собирает данные с ICS (температура, давление, статус помпы).

Показывает их оператору на экране (это веб-интерфейс).

Позволяет оператору отправлять команды обратно (включить/выключить, изменить уставку).

Пример SCADA: Открываешь браузер, видишь температуру помпы (55°) и кнопку «Выключить»

| Термин | Что это | Пример |
| :--- | :--- | :--- |
| **ICS** | Всё оборудование для управления процессами (железо + софт) | PLC, насос, датчик, конвейер |
| **SCADA** | Софт для мониторинга и управления ICS (интерфейс оператора) | Панель с графиками, кнопками, тревогами |
| **PLC** | Мозг системы — контроллер, который выполняет логику | Включает помпу при температуре > 80° |
| **RTU** | Удалённый контроллер для полевых объектов | Управляет скважиной в поле |
| **HMI** | Экран оператора (частный случай SCADA) | Сенсорная панель на заводе |
| **Modbus** | Протокол для общения с PLC (порт 502) | Читаем регистр 0 → получаем температуру |
| **Coil** | 1 бит (вкл/выкл) | Вентилятор: 1 = вкл, 0 = выкл |
| **Holding Register** | 16 бит (число) | Температура: 55 → 200 |
| **DCS** | Распределённая система для больших заводов | Управляет всей химической установкой |
| **MES** | Система управления производством (планирование) | Задаёт план выпуска продукции |
| **MTU** | Master Terminal Unit — центральный узел SCADA | Сервер, который опрашивает все PLC |
| **I/O** | Входы/выходы PLC (датчики и исполнители) | Вход: температура; Выход: включить клапан |


## 2. Архитектура (Как это выглядит)

```
[Оператор] → [HMI/SCADA] → [MTU] → [PLC] → [Датчики/Клапаны/Насосы]
                 ↑
            (Modbus, DNP3, IEC 61850)
```


## 3. Основные протоколы для атак

| Протокол | Порт | Для чего | Пример атаки |
| :--- | :--- | :--- | :--- |
| **Modbus TCP** | 502 | Чтение/запись регистров и койлов | Изменить температуру, остановить насос |
| **DNP3** | 20000 | Управление в энергетике | Отключить подстанцию |
| **IEC 61850** | 102 | Подстанции | Манипуляция защитами |
| **S7comm** | 102 | Siemens PLC | Чтение/запись байтов памяти |
| **EtherNet/IP** | 44818, 2222 | Rockwell Automation | Удалённое выполнение кода (CVE-2024-34026) |
| **OPC UA** | 4840 | Промышленный стандарт обмена данными | Чтение конфиденциальных параметров |


## 4. Типовые атаки на SCADA/ICS

| Атака | Суть | Пример |
| :--- | :--- | :--- |
| **Modbus Man-in-the-Middle** | Перехват и подмена команд | Оператор нажимает «Выключить», а команда идёт «Включить» |
| **Запись в регистры** | Изменение параметров без авторизации | Поднять температуру до 200 → перегрев → взрыв |
| **Управление койлами** | Включить/выключить оборудование | Выключить вентилятор → взрыв |
| **Чтение конфигурации** | Сбор информации о системе | Узнать адреса регистров, логику работы |
| **EtherNet/IP RCE** | Переполнение буфера в OpenPLC | CVE-2024-34026 (то, что ты пытался) |
| **Node-RED RCE** | Выполнение команд через exec-ноду | Если Node-RED открыт без пароля |
| **Дефолтные креды** | openplc:openplc, admin:admin, node-red:node-red | Вход в веб-панель, загрузка своего кода |
| **Отказ в обслуживании (DoS)** | Переполнение буфера, краш PLC | Остановка производства |


## 5. Что искать в ICS-пентесте

| Шаг | Что делаем | Инструменты |
| :--- | :--- | :--- |
| 1. Разведка | Ищем Modbus, DNP3, S7comm, EtherNet/IP | Nmap, Shodan, `nmap -p 502,102,44818,4840,20000` |
| 2. Сбор информации | Читаем регистры, узнаём адреса койлов | `pymodbus`, `modbus-cli` |
| 3. Поиск слабых мест | Нет авторизации, дефолтные креды, старые версии | `nmap --script modbus-*` |
| 4. Эксплуатация | Пишем в регистры, выключаем койлы | `write_register(0, 200)` |
| 5. Закрепление | Установка бэкдора через Node-RED или SSH | `exec`-нода в Node-RED |


## 6. Примеры команд для пентеста

### Сканирование Modbus-устройств
```bash
nmap -p 502 --script modbus-discover 10.113.133.14
```

### Чтение holding registers
```python
from pymodbus.client import ModbusTcpClient
client = ModbusTcpClient('10.113.133.14', port=502)
client.connect()
result = client.read_holding_registers(0)
print(result.registers[0])  # 55
client.close()
```

### Запись в holding register
```python
client.write_register(0, 200)  # поднять температуру до 200
```

### Чтение coils
```python
for i in range(20):
    result = client.read_coils(i)
    print(f"Coil {i}: {result.bits[0]}")
```

### Запись в coil
```python
client.write_coil(15, False)  # выключить вентилятор
```


## 7. Важно запомнить

1. **Modbus не требует авторизации** — если порт 502 открыт, ты можешь читать и писать без пароля.
2. **Регистры и койлы — это всё,** что есть в PLC. Найди их адреса — получишь контроль.
3. **Node-RED часто открыт** — зайди на `:1880`, если есть редактор — ты можешь выполнять команды.
4. **EtherNet/IP (порт 44818)** — известен RCE-уязвимостями (CVE-2024-34026).
5. **Дефолтные креды** — всегда пробуй `openplc:openplc`, `admin:admin`, `node-red:node-red`.


## 8. Для собеса

**«ICS/SCADA — это промышленные системы управления. В пентесте они опасны тем, что атака может привести к физическим последствиям: взрыв, отключение электроэнергии, остановка производства. Modbus — основной протокол, он не защищён, поэтому если порт 502 открыт, злоумышленник может управлять оборудованием без авторизации».**
