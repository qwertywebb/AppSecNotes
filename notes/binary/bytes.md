# Байты, hex и бинарные протоколы

## 1. Байт

**Байт** = **8 бит**. **Хранит** **число** **от 0** **до 255** (`2^8 = 256` **значений**).

**Всё**, **что** **уходит** **в** **сокет**, — **байты**. **Буква** `A` = **байт 65**. **Пробел** = **байт 32**.


## 2. Hex

**Hex** — **система** **счисления** **с** **основанием 16**. **Цифры**: `0-9`, `A-F`.

| Hex | Dec | Hex | Dec |
|---|---|---|---|
| `0` | 0 | `8` | 8 |
| `1` | 1 | `9` | 9 |
| `2` | 2 | `A` | **10** |
| `3` | 3 | `B` | 11 |
| `4` | 4 | `C` | 12 |
| `5` | 5 | `D` | 13 |
| `6` | 6 | `E` | 14 |
| `7` | 7 | `F` | **15** |

**1 байт** = **2 hex-цифры**. **Всегда**.

**`0x`** — **префикс** («**это** **hex**»).


## 3. Перевод hex → десятичное

**Формула:** **каждая** **цифра** × **16** **в** **степени** **позиции** (**справа** **налево**, **с 0**).

**Пример** `0x4f1`:

```
4 × 16² + 15 × 16¹ + 1 × 16⁰
= 4 × 256 + 15 × 16 + 1
= 1024 + 240 + 1
= 1265
```

**Важно:** `f = 15`, **не 10**.


## 4. Перевод десятичное → hex

**Делим** **на 16**, **записываем** **остатки**, **читаем** **снизу** **вверх**.

**Пример** 66:

```
66 ÷ 16 = 4, остаток 2
4 ÷ 16 = 0, остаток 4
```

**Остатки:** `2`, `4`. **Снизу** **вверх:** `4`, `2` → **`0x42`**.


## 5. Big-endian

**Старший** **байт** **первым**. **Сеть** **и** **XFS** **используют** **big-endian**.

**Пример:** `0x12345678` → **`12 34 56 78`**.

**Little-endian** — **наоборот** (**`78 56 34 12`**), **но** **не** **для** **XFS**.


## 6. Размер полей (XFS)

| Поле | Размер | Hex-цифр |
|---|---|---|
| `msg_type` | 1 байт | 2 |
| `command_id` | 4 байта | 8 |
| `length` | 2 байта | 4 |
| `data` | N байт | 2N |

**Правило:** **дополняй** **слева** **нулями** **до** **нужного** **размера**.

**Пример:** `0x4f1` → **`000004f1`** → **`00 00 04 f1`**.


## 7. Escape `\x`

**`\x`** + **2 hex-цифры** = **1 байт**.

**`\x41`** = **65** = **`A`**.
**`\x30`** = **48** = **`'0'`**.
**`\xff`** = **255**.
**`\x00`** = **0**.

**`\xff`** — **один** **байт**. **`\xf\xf`** — **неправильно**.


## 8. ASCII vs binary

| Что | Байт | Пример |
|---|---|---|
| **ASCII** `'0'` | `0x30` (48) | `printf '\x30'` |
| **Binary** 0 | `0x00` (0) | `printf '\x00'` |
| **ASCII** `'1'` | `0x31` (49) | `printf '\x31'` |
| **Binary** 1 | `0x01` (1) | `printf '\x01'` |

**Смотри** **на** **ответ** **сервера** — **он** **подскажет**, **что** **ждали**.


## 9. `length` и `data`

**`length`** = **количество** **байт** **в** `data`. **2 байта** **BE**.

**`data`** — **что** **угодно**: **строка**, **JSON**, **байты**. **Зависит** **от** **команды**.

| `data` | Длина | `length` |
|---|---|---|
| (пусто) | 0 | `00 00` |
| `"0"` | 1 | `00 01` |
| `"14084762"` | 8 | `00 08` |
| `{"count":40}` | 11 | `00 0b` |


## 10. Как **отправлять**

**Через** `printf`:

```bash
printf '\x02\x00\x00\x04\xf0\x00\x08'14084762 | nc 10.129.161.17 9100
```

**Через** **Python** (**надёжнее**):

```python
import socket, struct
data = b"14084762"
msg  = struct.pack(">B", 0x02)          # msg_type
msg += struct.pack(">I", 0x4f0)         # command_id (BE)
msg += struct.pack(">H", len(data))     # length (BE)
msg += data

s = socket.socket()
s.connect(("10.129.161.17", 9100))
s.send(msg)
length = struct.unpack(">H", s.recv(2))[0]
print(s.recv(length).decode())
```

**Python** **сам** **считает** `length` — **не** **ошибёшься**.


## 13. Частые **ошибки**

| Ошибка | Как **исправить** |
|---|---|
| **Забыл** **дополнить** **нулями** **до 4 байт** | `0x4f1` → `00 00 04 f1` |
| **Перепутал** **ASCII** **и** **binary** | **Смотри** **ответ** **сервера** |
| **Неправильный** `length` | `len(data)` **в** **Python** |
| **Little-endian** **вместо** **big-endian** | **Старший** **байт** **первым** |
| **`\xf\xf`** **вместо** **`\xff`** | **2** **hex-цифры** **после** `\x` |

## 14. Шпаргалка **по** **hex**

| Dec | Hex | Dec | Hex |
|---|---|---|---|
| 0 | `00` | 128 | `80` |
| 1 | `01` | 200 | `c8` |
| 10 | `0a` | 240 | `f0` |
| 15 | `0f` | 250 | `fa` |
| 16 | `10` | 255 | `ff` |
| 32 | `20` | 256 | `100` |
| 48 | `30` | 1000 | `3e8` |
| 64 | `40` | 1024 | `400` |
| 65 | `41` | 4096 | `1000` |


## 15. Итог

1. **Байт** = **256** **значений**.
2. **Hex** = **2** **цифры** **на** **байт**.
3. **`0x4f1`** = **`00 00 04 f1`** (**4** **байта**).
4. **Big-endian** — **старший** **байт** **первым**.
5. **`\x41`** = **1** **байт** = **65** = **`A`**.
6. **`length`** = **`len(data)`** **в** **2** **байтах**.
7. **Python** — **лучший** **способ** **собрать** **запрос**.
