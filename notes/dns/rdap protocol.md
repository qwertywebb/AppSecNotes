# C января 2025 года официально прекращена поддержка WHOIS протокола
# На смену пришел протокол RDAP (Registration Data Access Protocol)

## RDAP является современным:
* Использует HTTPS для передачи данных
* Возвращает структурированный и читаемый JSON
* Обеспечивает лучший контроль конфиденциальности

# Пример:
curl -s https://rdap.verisign.com/com/v1/domain/tryhackme.com | jq .

jq - для вывода в читаемом json формате
