**Отчет о пентесте машины Madness**

**Цель:** Получение полного доступа к системе (root) на машине Madness.


### 1. Разведка и обнаружение уязвимостей

**1.1. Сканирование сети**  
Первым этапом проведено сканирование портов с использованием Nmap. Обнаружены следующие открытые порты:

- **22/tcp** – SSH (OpenSSH)
- **80/tcp** – HTTP (Apache2, стандартная страница Ubuntu)

**1.2. Анализ веб-приложения**  
На главной странице веб-сервера обнаружена стандартная заглушка Apache. В ходе фаззинга директорий не найдено значимых путей (все запросы возвращали код 403). Однако в исходном коде страницы обнаружена скрытая ссылка на изображение:

```html
<img src="thm.jpg" class="floating_element"/>
<!-- They will never find me-->
```


### 2. Получение доступа к системе

**2.1. Стеганография в изображении**  
Изображение `thm.jpg` скачано для анализа. Первоначальная проверка показала, что файл не является валидным JPEG или PNG (`file thm.jpg` выдавал `data`). В ходе ручного анализа установлено, что файл имеет сигнатуру PNG (`89 50 4E 47`), однако расширение `.jpg` указывало на иной формат.

После замены первых четырёх байт на корректные для JPEG (`FF D8 FF E0`) изображение открылось и содержало скрытый путь:

```
/th1s_1s_h1dd3n
```

**2.2. Угадывание секретного параметра**  
На странице по пути `/th1s_1s_h1dd3n` требовалось ввести секретное число в параметре `secret=`. В комментариях HTML-кода указано, что секрет находится в диапазоне от 1 до 99. С помощью Burp Intruder выполнен перебор значений. При значении `73` получен ответ:

```
Urgh, you got it right! But I won't tell you who I am! y2RPJ4QaPF!B
```

**2.3. Извлечение учётных данных**  
Полученная строка использована в качестве пароля для извлечения скрытых данных из изображения `thm.jpg` с помощью `steghide`:

```bash
steghide extract -sf thm.jpg
```

Извлечён файл `hidden.txt`, содержащий:

```
wbxre:*axA&GF8dP
```

Имя пользователя закодировано с использованием ROT13 (`wbxre` → `joker`). Пароль остался без изменений. Учётные данные использованы для входа по SSH:

```bash
ssh joker@<IP>
```


### 3. Эскалация привилегий

**3.1. Поиск вектора эскалации**  
После получения доступа к системе запущен скрипт `linpeas` для выявления потенциальных векторов повышения привилегий. Обнаружен SUID-файл:

```
/bin/screen-4.5.0
```

**3.2. Эксплуатация уязвимости GNU Screen 4.5.0**  
Версия `screen` 4.5.0 подвержена известной уязвимости, позволяющей локальному пользователю повысить привилегии до root (CVE-2017-5618). Уязвимость позволяет перезаписать файл `/etc/ld.so.preload` и выполнить произвольный код с правами root.

Для эксплуатации использован готовый скрипт `screenroot.sh`, который:

1. Создаёт вредоносную библиотеку (`/tmp/libhax.so`), которая при загрузке изменяет владельца и права на SUID-оболочку (`/tmp/rootshell`).
2. Компилирует SUID-оболочку, выполняющую `/bin/sh` с правами root.
3. Использует уязвимость `screen` для записи пути к библиотеке в `/etc/ld.so.preload`.
4. Запускает `screen`, который загружает библиотеку, активируя SUID-оболочку.
5. Запуск `/tmp/rootshell` предоставляет шелл с правами root.

**3.3. Получение root**  
После выполнения эксплойта получен доступ от пользователя `root`:

```bash
whoami
root
```

Флаг пользователя `root` успешно извлечён.


### 4. Итоговый вывод

В ходе пентеста машины Madness были успешно реализованы следующие этапы:

1. **Разведка:** Сканирование портов, анализ исходного кода веб-страницы.
2. **Получение доступа:** Исправление заголовка JPEG, извлечение скрытого пути, перебор секретного параметра, извлечение учётных данных через `steghide`, вход по SSH.
3. **Эскалация до root:** Использование SUID-файла `screen` и эксплуатация уязвимости GNU Screen 4.5.0.

**Результат:** Полный контроль над системой достигнут. Компрометация корневого пользователя подтверждена.
